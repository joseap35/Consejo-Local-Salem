Configuración inicial

Sistema de Minutas · Consejo Local

Este sistema guarda las sesiones en Firebase Firestore, así que necesita la configuración de tu proyecto (la misma que usas en tus otros sistemas, o uno nuevo). La configuración se guarda solo en este navegador, no queda escrita en el archivo — así puedes publicar el HTML en GitHub Pages sin exponer tus llaves en el código.

  1. 1. Ve a la Consola de Firebase → Configuración del proyecto → Tus apps.
  2. 2. Copia el objeto firebaseConfig.
  3. 3. Pégalo abajo tal cual (formato JSON) y presiona Conectar.
  4. 4. En Firestore, crea la colección sesiones (se crea sola al guardar la primera sesión).
